## Goals / Non-Goals

**Goals:**

- 畫面與伺服器回給頁面的訊息只用一般用語。
- 一個 `test_server` 測試擋住之後新增的技術名稱。

**Non-Goals:**

- 程式識別字、API、環境變數、資料表、log、註解、README、`docs/`、bench 說明文字、命令列工具輸出都不改。
- 不改功能與版面，只換字。

## Decisions

### 用語對照

| 原本 | 改成 |
| --- | --- |
| 本機模型（語橋主機） | 本機（語橋主機） |
| 雲端 MAI（音訊會傳送到 Azure） | 雲端辨識（音訊會傳送到外部服務） |
| 雲端 MAI（標籤、分組、原文欄） | 雲端辨識；會議列表與成效指標的短標籤用「雲端」 |
| 本機 Confucius | 本機辨識 |
| 雲端大模型 | 雲端服務 |
| 外部模型服務、Azure（隱私提示） | 外部服務 |
| LDAP 帳號 | 公司帳號 |
| 紀要模型未設定 | 紀要功能尚未設定 |
| 問答需要紀要模型，目前未設定 | 問答功能尚未設定 |
| 回答由模型根據… | 回答由系統根據… |
| 模型提到「X」 | 紀要提到「X」 |
| Azure GPT-Realtime-Translate | 雲端翻譯服務 |
| 尚未設定 Azure 即時口譯（AZURE_…） | 即時口譯尚未設定，請聯絡系統管理員。 |
| 連不上 Azure 即時口譯（例外名） | 連不上翻譯服務，請稍後再試。 |
| 請確認 Docker 服務已啟動 | 請聯絡系統管理員 |
| WebSocket 連線失敗 | 連線失敗 |

隱私提示一定要讓使用者知道資料會不會離開語橋主機，所以保留「雲端」「本機」「外部服務」；只拿掉供應商與模型名稱。

### 管理員頁也一起改

使用者沒有區分角色，團隊管理頁與即時口譯頁（只有管理員看得到）也照同一份對照表改。

### 用測試掃描可見字串

在 `test_server` 加一個測試，讀 `webapp/static` 下所有 `.html`、`.js`：去掉 `<!-- -->`、`/* */`、`//` 註解後，收集標籤之間的文字、`title`／`placeholder`／`aria-label`／`alt` 屬性值，以及含中文字的字串或樣板字面值；再加上伺服器送給頁面的訊息常數（`minutes.NOT_CONFIGURED`、`qa.NOT_CONFIGURED`，以及 `interpret` 的未設定與連不上訊息）。禁用字：Azure、MAI、Confucius、Qwen、DeepSeek、Gemma、GPT、OpenAI、LDAP、Docker、WebSocket、vLLM、`MINUTES_`、`TRANSLATE_`、`AZURE_`、`.env`、模型。只檢查含中文字的字串，是為了避開 `engine === 'mai'` 這類識別字；純英文的可見字串目前只有品牌名「語橋 Live」等，不在禁用清單內。

## Implementation Contract

- **行為：** 一般成員與管理員在開會頁、隱私提示、會議列表、成效指標、紀要、問答、團隊管理、即時口譯頁上，都看不到上面 Context 列出的技術名稱，文字依「用語對照」顯示。紀要頁的外部服務提示不再帶模型名稱（`data.model` 不顯示）。
- **介面：** `/api/minutes/...` 未設定時的 400 detail 改為「紀要功能尚未設定」；問答未設定的訊息改為「問答功能尚未設定」；`/ws/interpret` 4503 的 close reason 改為「即時口譯尚未設定」，Azure 連不上時的 error 事件訊息改為「連不上翻譯服務，請稍後再試。」。JSON 欄位名稱與 engine 值不變。
- **失敗情況：** 無新增；只換訊息文字。
- **驗收：** `docker exec -w /app asr_confucius4-r2t2-app-1 python -m unittest -q test_server` 全部通過，包含新測試 `PlainWordingTests`；把舊字樣暫時放回任一檔案時該測試失敗。bench `interpret_e2e`、`translate_e2e`、`privacy_e2e`、`qa_e2e`、`series_e2e`、`ui_polish_e2e` 中期望舊字樣的地方改成新字樣後通過（需要能跑的就跑；需要付費或外部服務的不跑並註明）。
- **範圍：** 只改可見文字與對應的測試期望；不改版面、功能、API 結構、log、註解、README、`docs/`。

## Risks / Trade-offs

- 掃描只看含中文字的字串，純英文可見文字中的技術名稱會漏掉 → 目前的頁面沒有這種字串（2026-11-17 掃描結果），日後若出現需人工留意。
- 管理員排查問題時少了「哪個服務」的線索 → log 與 README 仍保留完整名稱，管理員看主機端即可。
