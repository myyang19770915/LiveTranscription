## 1. 登入頁動態

- [x] 1.1 寬螢幕左側有動態：功能卡依序（每 2 秒、順時針）亮起並送出同色光點沿虛線流到中央，中央圖示漣漪與呼吸光，虛線往中央流動、外圈軌道轉動、卡片浮動、Cloud／Local 光點與晃動、背景柔光飄移、「會議」流光、進場淡入。驗證：bench/login_e2e.mjs「the left side moves」檢查（20 個以上動畫在跑、至少一顆光點可見），並在明亮、深色主題擷取不同時間點的畫面人工確認。
- [x] 1.2 系統設定為減少動態時，所有動畫停止且不顯示光點與漣漪。驗證：bench/login_e2e.mjs「reduced motion: nothing moves」檢查（沒有任何動畫在跑、SVG 已暫停、光點 0 顆）。
- [x] 1.3 既有登入頁版面與登入互動不受影響。驗證：bench/login_e2e.mjs 其餘檢查全數通過。
