- [x] 1.1 寬螢幕（≥ 1200 px）的登入頁為參考圖版型：左側品牌、標題「讓每場會議，化為團隊的行動。」（「會議」主色）、副標，以及中心圖示＋兩層軌道＋虛線連線＋六張功能卡（即時轉錄、即時翻譯、會議紀要、待辦追蹤、搜尋問答、成效指標）＋上方 Cloud、下方 Local；右側面板有主題切換、「歡迎回到 語橋 Live」、帶圖示的帳號密碼欄位、眼睛圖示的顯示密碼、滿版登入按鈕、說明與版權。明亮、深色各有一組顏色。驗證：bench/login_e2e.mjs 在兩個主題 1440 寬檢查六張卡、軌道與中心圖示可見、卡片互不重疊，並人工比對截圖與參考圖。
