## Context

`meeting-review` 建立了校對頁（`/meetings/{id}`），`meeting-minutes` 建立了紀要頁（`/meetings/{id}/minutes`）。兩頁各自畫標頭，用灰色小字的 `back-link` 互相連結；紀要的證據時間點連到校對頁 `#seg-N`；校對頁的「▶ 重播」每次從頭播放，不能暫停。使用者回報切換不明顯、不流暢、看證據要來回跳頁、聽錄音不能暫停，以及列表兩顆按鈕大小不同。

這些修改已在 commit dff06a5、f7ccf9f 實作；本設計記錄已採用的做法，供驗證與日後維護。

## Goals / Non-Goals

**Goals:**

- 一場會議的兩個檢視看起來是同一頁的兩個分頁：同一個標頭、明顯的分頁列，切換時只換下方內容。
- 返回會議紀錄永遠回到使用者進來前的列表，分頁切換不增加返回步數。
- 在紀要頁內就能讀到並聽到證據，不必離開。
- 任何播放錄音的地方都能暫停、繼續。

**Non-Goals:**

- 單頁應用（SPA）或前端路由框架。
- 在側欄內修改逐字稿。
- 後端 API、資料表的任何變更。
- 為不支援跨頁轉場的瀏覽器模擬轉場。

## Decisions

### 會議頁共用標頭與分頁列

**Supersedes**: meeting-minutes / 紀要頁

`webapp/static/meeting-nav.js` 由兩頁共用，負責：返回連結、會議標題與資訊列（`MeetingNav.show(meeting)`，資料一律來自 `GET /api/meetings/{id}`，兩頁內容相同：團隊、開始時間、錄音長度或「沒有錄音」、語言、建立者）、分頁列（`#tabReview`、`#tabMinutes`，目前分頁 `aria-current="page"`）。頂部列副標題兩頁都是「會議紀錄」，不再各自顯示「會後校對」「會議紀要」。

紀要頁其餘內容沿用 meeting-minutes 的「紀要頁」決定（產生按鈕、摘要、四類條目、負責人、到期日、確認／駁回、新增、下載 Markdown），只有兩處改變：頂部連結改為共用標頭與分頁列；證據時間點改為開啟證據側欄（見下），連結的 `href` 仍指向校對頁 `#seg-N`，供中鍵或 Ctrl＋點擊在新分頁開啟。校對頁仍支援 `#seg-N`：載入後捲到並展開該段（不自動播放）。

替代方案：合併成單頁、以前端切換內容。切換最順，但兩頁各自的狀態（編輯中的條目、正在播放的段落）要整合，改動大；採用多頁加轉場已足夠。

### 分頁切換取代瀏覽紀錄並加轉場

一般點擊分頁以 `location.replace` 開啟另一頁，瀏覽紀錄筆數不變；中鍵、Ctrl／Cmd／Shift／Alt 點擊保留瀏覽器預設行為（另開分頁）。CSS `@view-transition { navigation: auto; }`，並為頂部列、返回連結、標題區、分頁列設定 `view-transition-name`，切換時這些區塊不動、內容淡入（約 0.18 秒）；`prefers-reduced-motion` 時關閉動畫。不支援的瀏覽器直接切換。

標題與資訊列先以 `sessionStorage` 中這場會議上次的內容畫出（鍵 `yq-meeting:<id>`），再以伺服器資料更新，避免切換時標題閃一下或撐開高度。

替代方案：一般連結（push）。每切換一次返回就多一步，使用者回報返回會在兩頁之間繞，不採用。

### 返回會議紀錄記住列表網址

從 `/meetings` 進入時，把 `document.referrer`（含篩選查詢字串）存入 `sessionStorage` 鍵 `yq-meeting-list`，返回連結的 `href` 設為該網址，沒有時為 `/meetings`。點擊時若瀏覽器支援 Navigation API，且前一筆瀏覽紀錄就是 `/meetings`，以 `navigation.back()` 返回（保留列表捲動位置）；否則依 `href` 前往。

替代方案：沿用 `document.referrer` 判斷（meeting-topics 的做法）。分頁切換後 referrer 變成另一個分頁，判斷失效，不採用。

### 證據側欄

紀要頁加 `<aside id="peek">`。點證據時間點（一般左鍵）開啟側欄並標示該條目（`.item.peeked`）：

- 標題列：條目類型（「待辦的證據」等）與條目內容；關閉鈕；Esc 也會關閉。
- 段落清單：引用的段落（`.cited`，綠框）與前後各一段上下文；不相鄰的區塊之間顯示「⋯」；被點的那段加強標示並捲入可視範圍。每段顯示原文、譯文。
- 有錄音時每段有播放鈕；引用的段落有「到校對頁修正」連結（`/meetings/{id}#seg-N`）。
- 段落資料來自 `GET /api/meetings/{id}`（與標頭同一次請求）；尚未載入時顯示「載入逐字稿中…」。
- 寬度 `min(440px, 100vw)`，從頂部列下方開始（不遮住帳號與主題按鈕）；視窗 ≥ 1100px 時紀要內容右側讓出空間，兩者並排；≤ 640px 改為高度 72vh 的底部面板。
- 條目修改後側欄標題跟著更新；條目被重新產生取代時側欄自動關閉。

替代方案：彈出對話框（modal）。會擋住紀要，無法邊看證據邊改條目，不採用。

### 播放鈕可暫停與繼續

播放器維持一個 `<audio id="player">`，記住目前載入的片段（段落編號與播放範圍）。播放鈕的行為：

| 狀態 | 按下後 |
| --- | --- |
| 播放器不是這一段，或這段已播完 | 重新載入並從頭播放這段 |
| 這段播放中 | 暫停 |
| 這段已暫停 | 從停下處繼續 |

按鈕文字依播放器的 `play`、`pause`、`ended`、`timeupdate` 事件就地更新，不重畫段落（不打斷編輯中的內容），按下後也立即更新。校對頁：「▶ 播放」／「❚❚ 暫停」／「▶ 繼續」，旁邊顯示「目前位置 / 片段結束」（會議時間軸上的 mm:ss）；展開某段時，焦點不在輸入框、選單、按鈕或連結上，空白鍵切換播放／暫停。證據側欄：「▶ mm:ss」（段落開始時間）／「❚❚ mm:ss」／「▶ 繼續 mm:ss」（目前位置）。「往前 2 秒」「往後 2 秒」照舊重新載入加長後的片段。

替代方案：使用瀏覽器內建的 `<audio controls>`。外觀與主題不一致、手機上占空間，且無法呈現會議時間軸位置，不採用。

### 列表按鈕尺寸與名稱

`.secondary-button.compact` 與 `.primary-button.compact` 同為 40px 高；列表按鈕名稱改為「會議紀要」（框線）與「逐字稿校對」（實心），與分頁名稱一致，說明文字同步。

## Implementation Contract

**Behavior**

- 校對頁與紀要頁顯示相同的標頭與分頁列；一般點擊分頁切換到另一頁，瀏覽紀錄筆數不變。
- 從列表進入後，不論切換分頁幾次，「返回會議紀錄」回到原本含篩選的列表。
- 紀要頁點證據開啟側欄，網址不變；側欄顯示引用段落與上下文、可播放；Esc 關閉；「到校對頁修正」開啟校對頁並展開該段。
- 校對頁與證據側欄的播放鈕可暫停、繼續（從原處），校對頁顯示目前位置，空白鍵切換。
- 列表兩顆按鈕同高。
- `.env.example` 有 `MINUTES_URL`、`MINUTES_MODEL`、`MINUTES_KEY` 的註解範例。

**Interface**

- `window.MeetingNav = {meetingId, show(meeting), clock(ms), LANG}`。
- 頁面元素：`#back`、`#title`、`#meta`、`#tabReview`、`#tabMinutes`；紀要頁 `#peek`、`#peekList`、`#peek-<seq>`、`.peek-play[data-play]`；校對頁 `.play-button[data-play]`、`#playtime-<seq>`。
- `sessionStorage`：`yq-meeting-list`（列表網址）、`yq-meeting:<id>`（標題與資訊列快取）；讀寫失敗時忽略。

**Failure modes**

- 錄音載入失敗：頁面通知顯示伺服器訊息或「無法載入錄音」，按鈕維持未播放狀態。
- 會議沒有錄音：校對頁顯示「這場會議沒有錄音」，側欄只顯示時間、沒有播放鈕。
- `sessionStorage` 不可用：標頭等伺服器資料回來才顯示，返回連結為 `/meetings`。
- 不支援 Navigation API：返回連結依 `href` 前往列表（捲動位置不保留）。

**Acceptance criteria**

- `bench/minutes_e2e.mjs`：證據開側欄而非換頁、側欄含上下文、Esc 關閉、分頁切換後標頭一致、分頁切換不增加瀏覽紀錄、返回回到列表、側欄連結開啟校對頁該段、400px 無水平捲動。
- `bench/playback_e2e.mjs`：校對頁播放→暫停（位置不動）→繼續（從原處）、位置顯示、空白鍵暫停；側欄播放→暫停→繼續。
- 既有單元測試（`python -m unittest test_server`）與 `bench/*check.js` 維持通過（後端無變更）。

**Scope**

- 範圍內：上列前端頁面、樣式、`.env.example`、README 與驗收腳本。
- 範圍外：後端、API、資料表；首頁（即時轉錄頁）沒有錄音播放，不受影響。

## Risks / Trade-offs

- [跨頁轉場只在 Chromium 系瀏覽器生效] → 其他瀏覽器直接切換；標頭快取仍可避免標題閃爍。
- [`location.replace` 讓「上一頁」無法回到另一個分頁] → 這是刻意的：兩個分頁視為同一頁的兩個檢視，返回的目標是列表。
- [側欄在 1100px 以下會蓋住部分紀要] → 可隨時以 Esc 或關閉鈕收起；手機改為底部面板。
- [空白鍵與頁面捲動衝突] → 只在展開某段且焦點不在可輸入或可點擊元素時攔截。
